# Study QB
Study QB is an app that allows for a streamlined studying process to improve at quizbowl. It can extract useful clues from questions, save them, and facilitate reviewing.

Features include...
 - Common clue analysis
 - Flashcards, with different clue review modes
 - Dynamic frequency lists
 - Spaced repetition
 - Review session tracking & stats
 - Customizable study reminders

## Technologies
This project was created primarily using the Swift Programming Language. The SwiftUI and SwiftData libraries were utilized for the user interface and data flow respectively. The AI clue analysis models are accessed using the GroqAPI, and the analyzed questions were pulled using the QBReader API (https://www.qbreader.org).
